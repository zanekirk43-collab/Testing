# How to use this vault

## CODE workflow
- **Capture**: new note in `0-Inbox/` (or today's daily note). Keep only what resonates.
- **Organize**: file by *actionability*, not topic: Projects → Areas → Resources → Archives.
- **Distill**: progressive summarization. Bold the key passages, then ==highlight== the best of those, then add a 2-line summary at the top.
- **Express**: turn notes into output (posts, decisions, deliverables).

## PARA rules
- **Project**: has a goal *and* a deadline.
- **Area**: a standard to maintain, no end date.
- **Resource**: interesting, not currently actionable.
- **Archive**: anything inactive. Move it, don't delete it.

## Conventions
- Link with relative markdown links (Obsidian's settings are set to create these), so links work on GitHub too.
- End notes with a `Related:` line so backlinks and the graph carry meaning.
- Use frontmatter: `title`, `date`, `tags`.
- Templates live in `Templates/`. Use them via the core Templates plugin (Settings → Core plugins → Templates, folder `Templates`).

## Rhythm
- Daily: capture into the [daily note](../Templates/Daily%20note.md).
- Weekly: run the [weekly review](../Templates/Weekly%20review.md).
