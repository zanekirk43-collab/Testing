# Second Brain

The entry point to this vault. Open this folder in Obsidian ("Open folder as vault"). It also reads fine on GitHub.

## How it works

1. **Capture** anything worth keeping into [Inbox](0-Inbox/INDEX.md), fast and unsorted.
2. **Organize** weekly: move each inbox note into the PARA folder where it will be *used*.
3. **Distill**: bold the key lines, then highlight the best of the bold (progressive summarization).
4. **Express**: use the notes to ship something, then archive what's done.

See [How to use this vault](3-Resources/How%20to%20use%20this%20vault.md) for the full workflow.

## Folders

- [Inbox](0-Inbox/INDEX.md): unsorted captures; empty it weekly.
- [Projects](1-Projects/INDEX.md): active work with a goal and a deadline.
- [Areas](2-Areas/INDEX.md): ongoing responsibilities with no end date.
- [Resources](3-Resources/INDEX.md): topics and reference material of interest.
- [Archives](4-Archives/INDEX.md): inactive items from the three above.
- [Daily](Daily/INDEX.md): daily notes and journal.
- [Templates](Templates/INDEX.md): note templates (Obsidian core Templates plugin).
